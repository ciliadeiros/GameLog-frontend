# Testes de unidade do GameLog

**A aplicação funcional está na pasta `gamelog-app/`.** A antiga pasta `src/` corresponde ao protótipo de telas e não foi alterada.

Para rodar os testes do frontend, entre em `gamelog-app/` e leia o guia **`TESTES-README.md`**.

Os testes adicionados usam Vitest e React Testing Library com mocks. **Não é necessário iniciar o backend**.
